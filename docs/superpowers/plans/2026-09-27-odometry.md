## Interface for full replay

Input CSV without header: `receive_ns,stamp_ns,C|F|R|MF|RF|MV|RV,value[,value...]`.
C is notch; F/R km/h; MF/RF latitude,longitude,altitude,status; MV/RV x,y,z velocity m/s.
Output CSV includes `stamp_ns,receive_ns,velocity_mps,distance_m,position_valid,x,y,z,front_slip,rear_slip,model_only,gnss_corrections`.
CLI accepts vehicle ID, route map, drive table and GNSS policy (`startup` or `corrections`). Reference messages are never serialized into its input.

## Verification commands

Use a standalone CMake build for portable tests, `python3 -m unittest discover -s evaluation/tests`, and ROS `colcon build`/`colcon test` in the dedicated Docker environment. Preserve failed-before/passed-after evidence for behavioral tests. Each experiment stores the command, git state, config and data hashes; report real ROS numbers separately from nearest-stamp offline approximations.

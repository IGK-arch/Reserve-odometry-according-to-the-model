## Что можно заявлять по текущим измерениям

- Локальный **GNSS-прокси** на validation только для `30618`: RMSE скорости 0,0345 м/с против 0,0672 м/с у причинного среднего колёс; медиана абсолютного конечного дрейфа 0,188% против 0,233% на 12 длинных bag; медианная 3D RMSE 2,99 м против 3,82 м на 13 bag. Для `30639` отдельной validation-сессии нет.
- На holdout общий RMSE скорости 0,1192 м/с против 0,1241 м/с, но медиана абсолютного конечного дрейфа **хуже**: 0,664% против 0,340%. Для `30639` 3D-прокси особенно слаб: медиана RMSE 43,28 м против 34,28 м у базы на 9 bag. Это нельзя скрывать за общим улучшением скорости.
- На полном holdout bag `30618_af7496f0` фактическая ROS-нода дала RMSE скорости **0,17481 м/с** относительно GNSS-прокси и 3D RMSE **5,98 м** относительно dual-GNSS `base_link` прокси. Расхождение ROS с offline CLI на одинаковых метках мало: RMSE **0,00273 м/с**. Это измерение одной поездки, не среднее по holdout.
- Слитой высокоточной эталонной локализации жюри в предоставленных bag нет. GNSS-скорости также могут ошибаться; приведённые числа не являются официальным score. Holdout использовался при выборе режима таблицы по трамваю и уже не полностью независим для финальной конфигурации.
- Каталог остановок и snap в [STOP_LANDMARKS.md](STOP_LANDMARKS.md) остаются исследовательским экспериментом и **не включены** в production-ноду из-за ложных привязок на `30639`.

## Известные границы решения

Без стартовой абсолютной позы невозможно восстановить мировой MGRS только по трём скалярным входам; режим `odom` сообщает относительное движение. На западной конечной есть две ветки: карта B выбрана по обучающей частоте, карта A при известном маршруте выбирается параметром `map_file`. Никакой из разрешённых сигналов не сообщает стрелку. Майские записи `30639` показывают отличие общего масштаба колёс/GNSS от августовской калибровки: без независимого ориентира этот постоянный сдвиг неидентифицируем. Высотный датум GNSS сверх числового `NavSatFix.altitude` организаторами не уточнён.

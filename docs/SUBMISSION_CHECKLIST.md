# Комплект для сдачи

Новые вводные разрешают GNSS-коррекции и дают объединённый эталон. Статус и численные доказательства находятся в [RESULTS.md](RESULTS.md), метод проверки — в [VALIDATION_PROTOCOL.md](VALIDATION_PROTOCOL.md). Старые графики и CSV не использовать как текущую сводку.

## Шесть полей формы

| Поле | Что приложить |
|---|---|
| ROS 2-пакеты и исходники | Репозиторий команды; `ros2_ws/src/tram_odometry`, `ros2_ws/src/tram_vehicle_msgs`; либо проверенный `release/tram_odometry_source.zip` |
| Описание алгоритма | [CORE_MODEL.md](CORE_MODEL.md): модель тяги/торможения, адаптация, колёса, GNSS-привязка и отказы |
| Картографическая часть | [MAP_METHOD.md](MAP_METHOD.md), обе train-карты, официальный профиль высоты и JSON происхождения |
| Инструкция запуска | [JURY_CHECK.md](JURY_CHECK.md), конфигурация по умолчанию 30618, [Docker-проверка](../tools/docker/README.md) |
| Метрики и быстродействие | [RESULTS.md](RESULTS.md), `evaluation/results/**/*.json`, график `reference_comparison.png`; разделять GNSS-прокси, офлайн-эталон и официальный ROSchecker |
| Ограничения и дальнейшая работа | Последний раздел [RESULTS.md](RESULTS.md): общий slip, отсутствие GNSS на развилке, ориентация на петлях, различие эталонов |

## Технический комплект

- [x] Оба ROS-пакета собираются Ubuntu 22.04/ROS 2 Humble из исходников.
- [x] Стандартный `colcon test` и переносимый `ctest` запускают C++ regression-тесты; проверки не исчезают при Release/NDEBUG.
- [x] Python-тесты проверяют OdometryCDR, точные наносекунды, signed velocity, XYZ, common mask, некорректные выходы, корректное завершение процессов и измерение ресурсов.
- [x] Общий C++ код используется нодой и полным replay. Входной CSV отвергает неизвестные каналы; эталон не поступает алгоритму.
- [x] Есть тесты stale/future/duplicate GNSS, выбросов, зависших координат, возврата после пропуска, согласованности выбора ветки, rover-only старта на повороте и сброса bag time.
- [x] Проверена детерминированная генерация official elevation по JSON организаторов без использования эталонногоbag.
- [x] Изменение скорости подтверждено train/validation и 284 двойными обрывами колёс. Историческийholdout пересчитан текущим кодом.
- [x] Полный ускоренныйROSsmoke с официальнымchecker прошёл; окончательные 1× отчёты сохраняются отдельно.
- [x] Три полных прогона 1× завершены штатно: 3D RMSE 5,684→1,541 м, RSS 24,54 MiB, p95 задержки положения 4,58 мс; отчёты в RESULTS.
- [x] Зафиксированы отдельные эксперименты и отклонённые подходы; измеренная версия прошла 13 C++ наборов и 37 Python-тестов. После слияния 15 C++ наборов, 37 Python-тестов и 15 ROS CTest прошли; подробности в PUBLISH_VERIFICATION.
- [x] Source-only архив собран и проверен по явному allowlist; контрольная сумма находится в release/SHA256SUMS.txt.

## Действия команды при отправке

Предоставить жюри доступ к [приватному репозиторию команды](https://github.com/IGK-arch/Reserve-odometry-according-to-the-model) или передать проверенный архив согласно форме организаторов. Push в репозиторий команды не отправляет форму организаторам. До дедлайна 27 сентября 23:59 МСК выбрать именно эту проверенную версию и приложить согласованные отчёты.

`context`, сырой датасет, rosbags, бинарные файлы, каталоги сборки и временные записи не входят в архив. Использовать `python3 tools/make_release.py`, не архивировать весь рабочий каталог. Основной датасет загружен и доступен локально в `dataset/data`.

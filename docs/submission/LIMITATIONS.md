# Ограничения и развитие

## Ограничения поставляемой версии

| Ситуация | Поведение / ограничение |
|---|---|
| Оба колеса одновременно скользят или выдают согласованную ошибку | Ошибка не всегда наблюдаема по колёсам и ручке. Эвристика обнаруживает часть точных зависаний, но не гарантирует распознавание общего плавного скольжения. |
| Долго нет исправных колёс | Скорость прогнозируется моделью. Неизвестные загрузка, уклон, сцепление и реальная тяга увеличивают ошибку пути. |
| Здоровое точное плато после разгона | Возможно ложное распознавание общего зависания. |
| Нет стартовой GNSS-привязки | По умолчанию выдаются относительные координаты `odom` после 5 с. Абсолютную позицию без известной начальной точки восстановить нельзя. |
| Для выбранной стартовой привязки нет согласованного курса двух антенн | Используется направление кузова по карте, а без карты — заданный курс; при отличии фактической ориентации возможна начальная ошибка. RTK-привязка требует RTK-пары для курса; при запасной привязке без RTK допустима согласованная пара обычных fix. |
| Нет GNSS около развилки | По одним скорости и ручке нельзя однозначно выбрать ветку. Сохраняется предыдущая или заданная карта. |
| Участок вне карты, новая петля или тупик | Достоверное продолжение траектории отсутствует. Поставлены восстановленные пути и конечные доступного маршрута; произвольные пути депо не покрыты. |
| Ошибочные GNSS | Проверяются давность, скачки, геометрия и согласованность, но общий правдоподобный сдвиг обеих антенн может пройти проверки. |
| Задний ход | Знак движения не оценивается: скорость ограничена диапазоном 0–25 м/с. |
| Высота и неопределённость | Официальный профиль высоты покрывает часть линии. Вне него используется высота карты; ковариации являются инженерными оценками, а не гарантированными доверительными границами. |

Сравнение выполнено на доступных записях и одном открытом комплексированном эталоне. Это не результат скрытого тестирования организаторов. Исторический holdout уже анализировался при разработке.

## План после хакатона

| Приоритет | Работа | Как проверять результат |
|---|---|---|
| 1 | Собрать новые сессии 30618 с независимым эталоном, разной загрузкой и реальными отказами | Зафиксировать новые сессии до выбора алгоритма; отдельно считать штатные ошибки и ошибки при отказах |
| 2 | Уточнить модель тяги, торможения и переходов между режимами | Сравнивать ошибки скорости/пути через 1, 3 и 5 с потери колёс; проверять p95 и худшие случаи |
| 3 | Улучшить распознавание общего скольжения и зависания | Проверять реальные отказы вместе с исправным равномерным движением, чтобы контролировать ложные срабатывания |
| 4 | Уточнить геометрию обеих колей, конечных и развилок | Проверить прямое XYZ-сравнение без выравнивания, выбор ветки и ошибки на малых радиусах |
| 5 | Провести длительные испытания на целевом компьютере | Измерить пропуски выходов, частоту, задержки, CPU/RAM и восстановление после перезапуска |

Двухсостоянийный фильтр Калмана исследован: средние ошибки ряда обрывов меньше, но отдельные ошибки и скорость на открытом эталоне хуже. Он не включён в поставляемую версию; повторное внедрение требует прохождения перечисленных проверок.

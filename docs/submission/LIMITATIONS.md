# Ограничения и развитие

## Ограничения поставляемой версии

| Ситуация | Поведение / ограничение |
|---|---|
| Оба колеса одновременно скользят или выдают согласованную ошибку | Предусмотрено обнаружение точного зависания обоих датчиков после разгона или торможения. Общее плавное скольжение остаётся ограничением наблюдаемости. |
| Долго нет исправных колёс | При потере колёс скорость прогнозируется моделью. Точность длительного прогноза зависит от загрузки, уклона и сцепления. |
| Неизменные показания исправных датчиков после разгона | Возможны ложные срабатывания детектора зависания. |
| Нет стартовой GNSS-привязки | Без GNSS система переходит к относительной одометрии `odom` после 5 с. Для абсолютных координат требуется начальная привязка или заданная начальная точка. |
| Для выбранной стартовой привязки нет согласованного курса двух антенн | Используется направление по карте либо заданный курс. Точность старта зависит от соответствия этого направления фактическому. |
| Нет GNSS около развилки | На известном участке 30618 ветка выбирается по устойчивому сочетанию тяги и скорости. При другом режиме проезда возможен ошибочный выбор. В остальных условиях сохраняется ранее выбранная или заданная ветка. |
| Остановка около известного маркера | Коррекция использует каталог обучающих поездок. Отличие места стоянки от маркера может увеличить позиционную ошибку. Для 30639 и альтернативной ветки коррекция отключена. |
| Момент применения поправки остановки | Привязка положения обновляется одним шагом. На проверочной записи измерен сдвиг 1,536 м при нулевой скорости. |
| Участок вне карты, новая петля или тупик | Карта покрывает восстановленные участки доступного маршрута и конечные. Для новых петель, тупиков и путей депо требуется расширение карты. |
| Ошибочные GNSS | GNSS проходят проверки давности, скачков и геометрической согласованности. Сохраняется чувствительность к согласованному смещению обеих антенн. |
| Направление движения | Рабочий диапазон — движение вперёд со скоростью 0–25 м/с. |
| Высота и неопределённость | На участке официального профиля используется его высота, на остальных участках — высота карты. Ковариации задают приближённую инженерную оценку неопределённости. |

Сравнение выполнено на доступных записях и открытом комплексированном эталоне. Исторические наборы уже анализировались при разработке. Правило выбора ветки также проверялось на использованной при разработке выборке. Проверка на новых независимых поездках ветки A входит в план развития.

## План после хакатона

| Приоритет | Работа | Как проверять результат |
|---|---|---|
| 1 | Собрать новые сессии 30618 с независимым эталоном, разной загрузкой и реальными отказами | Зафиксировать новые сессии до выбора алгоритма. Отдельно считать штатные ошибки и ошибки при отказах |
| 2 | Уточнить модель тяги, торможения и переходов между режимами | Сравнивать ошибки скорости/пути через 1, 3 и 5 с потери колёс. Проверять p95 и худшие случаи |
| 3 | Улучшить распознавание общего скольжения и зависания | Проверять реальные отказы вместе с исправным равномерным движением, чтобы контролировать ложные срабатывания |
| 4 | Уточнить геометрию обеих колей, конечных и развилок | Проверить прямое XYZ-сравнение, выбор ветки и ошибки на малых радиусах |
| 5 | Провести длительные испытания на целевом компьютере | Измерить пропуски выходов, частоту, задержки, CPU/RAM и восстановление после перезапуска |

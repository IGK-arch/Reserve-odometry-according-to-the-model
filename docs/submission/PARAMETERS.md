# Допущения и параметры

## Допущения

| Допущение | Следствие |
|---|---|
| Движение вперёд по известному рельсовому маршруту | Оцениваются неотрицательная скорость и пройденный путь. Геометрия задаётся картой |
| Положение ручки связано с тягой и торможением | Реальный момент приближается моделью с запаздыванием и ограничением мощности |
| Масса, радиус, сопротивления известны приближённо | Малые устойчивые ошибки компенсируются калибровкой и ограниченной адаптацией |
| Числа колёсных топиков данного датасета — км/ч | Перед расчётом выполняется перевод в м/с и индивидуальная поправка масштаба |
| Для абсолютной привязки используются GNSS-координаты | Начальную позицию также можно задать вручную |
| Карта и калибровки подготовлены до запуска | Карта и калибровки заранее подготовлены по обучающим данным и включены в пакет |

Ограничения этих допущений и план развития: [LIMITATIONS.md](LIMITATIONS.md).

## Как изменить параметры

Скопируйте [default.yaml](../../ros2_ws/src/tram_odometry/config/default.yaml), измените значения внутри `tram_odometry.ros__parameters` и передайте абсолютный путь:

```bash
ros2 launch tram_odometry tram_odometry.launch.py \
  config:=/absolute/path/to/custom.yaml vehicle_id:=30618 route_direction:=auto
```

Значения читаются при запуске. После изменения перезапустите ноду. `vehicle_id`, `route_direction` и `use_sim_time` задаются аргументами запуска и перекрывают одноимённые значения YAML. По умолчанию `use_sim_time:=true`.

Для проверки используйте геометрию и систему координат по умолчанию. Начало локальной системы координат ENU должно соответствовать используемой карте.

Константы `N=4`, `i=6`, `η=0.84`, времена привода 0.45/0.27 с и предел скорости 25 м/с задаются в [EstimatorConfig](../../ros2_ws/src/tram_odometry/include/tram_odometry/estimator.hpp) и изменяются с пересборкой пакета. Полный снимок измеренной конфигурации: [Параметры проверенной конфигурации](../../evaluation/results/round4/ros_effective_parameters.log).

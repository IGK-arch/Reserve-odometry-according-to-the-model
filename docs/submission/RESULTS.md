# Точность и быстродействие

**На 13 валидационных записях 30618 с GNSS только на старте: RMSE положения 2,615 м, скорости 0,033 м/с.** На контрольной записи с комплексированным эталоном офлайн-пересчёт дал RMSE положения **1,545 м**, скорости **0,048 м/с**.

RMSE — среднеквадратическая ошибка. Координаты и скорость сравниваются напрямую в исходной системе координат и по временным меткам сообщений.

## Проверка с GNSS только на старте

Полное C++-ядро обработало 13 валидационных записей трамвая 30618. Алгоритму поступали контроллер, скорости тележек и GNSS-координаты первых **1,5 с**. Последующие GNSS-измерения использовались для оценки точности. Эталон положения получен по согласованной паре GNSS-приёмников. Карта и каталог остановок подготовлены по обучающим поездкам.

## Быстродействие и ROS-интеграция
